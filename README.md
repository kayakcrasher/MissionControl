# MissionControl

Mars Robot Colony Simulator — 2D isometric rover/robot colony sim.

## Stack
- Godot 4.3 (GL Compatibility renderer)
- GDScript
- Android APK built via GitHub Actions

## Build
Push to `main`. Grab the APK from the **Actions** tab → latest run → `MissionControl-debug` artifact.

## Controls (M1)
- WASD — pan
- Mouse wheel — zoom
- Right/middle drag — pan
- Touch drag — pan
